# EchoBeyond
### Эхо по ту сторону

**Narrative puzzle game — playable prototype**

EchoBeyond is a narrative puzzle game prototype built around an
unexpected connection between the player and four students trapped
somewhere beyond an unknown boundary.

The player communicates with the characters through a mysterious
interface and gradually discovers what happened to them.

---

## 🎮 Current Prototype

The current playable build includes the opening sequence of the game:

- animated connection screen;
- sequential system messages;
- branching dialogue;
- player dialogue choices;
- character message bubbles;
- typing indicator animation;
- custom visual interface;
- story data separated from UI logic.

The prototype is being developed incrementally from the original
game concept and scenario.

---

## ✦ Visual Style

The interface combines:

- dark backgrounds;
- warm golden and violet light;
- glowing perimeter effects;
- minimalist dialogue bubbles;
- subtle animation.

The visual language is intended to create a feeling of an
unknown digital connection gradually becoming something more mysterious.

---

## 🧩 Narrative

The story begins when an unknown connection appears.

Four students from a musical academy — **Cadence, Harmony, Reed and Lyra** —
have discovered an unusual musical sequence in an archival text.

After attempting to reproduce it, something goes wrong.

The library changes.

The connection appears.

And someone — or something — is now on the other side.
